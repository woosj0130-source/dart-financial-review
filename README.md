# DART 재무제표 추가 검토 포인트 탐색 도구

DART Open API에서 기업의 최근 3개년 연결재무제표를 불러와 핵심 계정의 변화와 주요 재무비율을 계산하는 Streamlit 앱입니다.

이 도구는 공개 재무정보를 이용한 스크리닝 도구입니다. 특정 회계처리의 적정성이나 부정·오류 여부를 판단하지 않습니다.

## 주요 기능

- 기업명 검색 및 기업 선택
- 최근 3개년 연결재무제표 조회
- 8개 핵심 계정 금액 표시
- 전년 대비 증감률 및 주요 재무비율 계산
- 조정 가능한 기준에 따른 추가 검토 포인트 안내
- 재무 변화 그래프
- 자료 없음 및 계산 불가 처리

## 실행 방법

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

앱 화면에서 본인의 DART API Key를 입력한 후 기업을 검색합니다. API Key는 코드와 저장소에 저장하지 않습니다.

## 한계

- 최근 연간 사업보고서의 연결재무제표만 이용합니다.
- 기업별 사용자 정의 계정 때문에 일부 항목이 자료 없음으로 표시될 수 있습니다.
- 검토 기준은 보편적인 감사기준이 아니라 사용자가 조정할 수 있는 초기 스크리닝 조건입니다.
- 업종 비교, 주석 분석, 부정·오류 판단은 수행하지 않습니다.
